# Project Summary: Smart Garden IoT System (ESP32-C3 Mini)

## 1. System Architecture Idea (Combo 1)
* **Hardware (Local):** ESP32-C3 Mini reads sensors and drives relays. Uses `WiFiManager` to prevent hardcoding WiFi credentials (creates a Captive Portal interface for user to input school/home WiFi via smartphone).
* **Database (Cloud Realtime):** Firebase Realtime Database handles live data sync and UI manual control switches.
* **Data Logging (History):** Web Frontend listens to Firebase and pushes sensor logs into **MongoDB Atlas** via *MongoDB Data API* every 5 minutes (offloading heavy network/crypto tasks from ESP32).

---

## 2. Hardware Connections (ESP32-C3 Mini)

| Component | Pin Component | Pin ESP32-C3 | Power Source | Notes |
| :--- | :--- | :--- | :--- | :--- |
| **Main Power** | VIN / GND | V5 / GND | 5V Output from Buck | Buck converter steps down 12V Adapter to 5V |
| **Soil Moisture** | AUOT (Analog) | **GPIO 1** | **5V Output from Buck** | Capacitive 3-pin version (Needs 5V to boot properly, signal output is safely under 3.3V) |
| **Light Sensor (GY-302)** | SDA / SCL | **GPIO 8 / GPIO 9** | **3.3V (3V3)** | BH1750 Chip via I2C. ADDR pin is left disconnected (`0x23`) |
| **Water Float Switch** | Signal 1 / 2 | **GPIO 6 / GND** | Internal Pullup | Configured as `INPUT_PULLUP` |
| **Relay Channel 1 (Pump)**| IN1 | **GPIO 4** | 5V Output from Buck | Jumper set to **HIGH** trigger. Drives 5V Submersible Pump |
| **Relay Channel 2 (Light)**| IN2 | **GPIO 5** | 5V Output from Buck | Jumper set to **HIGH** trigger. Drives 12V LED Panel |

> ⚠️ **Anti-Siphon Note:** Due to the water tank being higher than the soil beds, a siphon effect occurs. Fix by poking a 1mm anti-siphon hole at the highest point of the pump tube inside the tank, or keeping the outlet nozzle higher than the max water level.

---

## 3. Core Logic Requirements
1.  **WiFi Manager:** If connection to stored WiFi fails, host AP `ESP32_TuoiCay_Config` to configure new network parameters.
2.  **Safety Interlock (Float Switch):** If the water level is LOW (`digitalRead(WATER_FLOAT_PIN) == HIGH`), **force terminate** the pump instantly (manual and automatic mode) to prevent dry running.
3.  **Smart Pump Interval (Auto Mode):** If soil moisture raw value $\ge$ `soil_min` (meaning dry), turn on pump for **5 seconds**, then turn off and wait **10 seconds** for water to soak in before evaluating the soil sensor again. Stop once value reaches $\le$ `soil_max`.
4.  **Smart Lighting (Auto Mode):** Turn on the 12V light if `lux` < `lux_min`.
5.  **Manual Overrides:** Web UI switches (`pump_manual`, `light_manual`) bypass automatic logic (except for the water float safety check).

## 4. Hardware Validation Code (Production Base)

```cpp
#include <Wire.h>
#include <BH1750.h>
#include <WiFiManager.h>
#include <Firebase_ESP_Client>

#define FIREBASE_HOST "YOUR_PROJECT-default-rtdb.firebaseio.com"
#define FIREBASE_AUTH "YOUR_FIREBASE_SECRET_TOKEN"

#define SOIL_PIN 1         
#define WATER_FLOAT_PIN 6  
#define PUMP_PIN 4         
#define LIGHT_PIN 5        

BH1750 lightMeter;
FirebaseData fbdo;
FirebaseAuth auth;
FirebaseConfig config;

int soilRaw = 4095;
float lux = 0.0;
bool isWaterLow = true;

int soilMin = 3000;        
int soilMax = 1500;        
float luxMin = 200.0;      
bool pumpManual = false;   
bool lightManual = false;  

unsigned long lastPumpTime = 0;
unsigned long lastFirebaseUpload = 0;
bool isPumpIntervalWaiting = false; 
const unsigned long PUMP_RUN_DURATION = 5000; 
const unsigned long PUMP_WAIT_DURATION = 10000; 

void setup() {
  Serial.begin(115200);
  // while (!Serial); // Commented out to allow standalone operation without USB

  pinMode(PUMP_PIN, OUTPUT);
  pinMode(LIGHT_PIN, OUTPUT);
  digitalWrite(PUMP_PIN, LOW);
  digitalWrite(LIGHT_PIN, LOW);
  pinMode(WATER_FLOAT_PIN, INPUT_PULLUP);

  Wire.begin(8, 9);
  lightMeter.begin(BH1750::CONTINUOUS_HIGH_RES_MODE);

  WiFiManager wm;
  wm.autoConnect("ESP32_TuoiCay_Config");

  config.database_url = FIREBASE_HOST;
  config.signer.tokens.legacy_token = FIREBASE_AUTH;
  Firebase.reconnectNetwork(true);
  Firebase.begin(&config, &auth);
}

void loop() {
  if (!Firebase.ready()) return;
  unsigned long currentMillis = millis();

  // Task 1: Read Sensors & Sync Firebase (Every 2 seconds)
  if (currentMillis - lastFirebaseUpload >= 2000) {
    lastFirebaseUpload = currentMillis;

    soilRaw = analogRead(SOIL_PIN);
    lux = lightMeter.readLightLevel();
    isWaterLow = (digitalRead(WATER_FLOAT_PIN) == HIGH); 

    Firebase.RTDB.setInt(&fbdo, "/sensor/soil_raw", soilRaw);
    Firebase.RTDB.setFloat(&fbdo, "/sensor/lux", lux);
    Firebase.RTDB.setString(&fbdo, "/sensor/water_status", isWaterLow ? "HET_NUOC" : "CON_NUOC");

    if (Firebase.RTDB.getInt(&fbdo, "/setting/soil_min")) soilMin = fbdo.to<int>();
    if (Firebase.RTDB.getInt(&fbdo, "/setting/soil_max")) soilMax = fbdo.to<int>();
    if (Firebase.RTDB.getFloat(&fbdo, "/setting/lux_min")) luxMin = fbdo.to<float>();
    if (Firebase.RTDB.getBool(&fbdo, "/control/pump_manual")) pumpManual = fbdo.to<bool>();
    if (Firebase.RTDB.getBool(&fbdo, "/control/light_manual")) lightManual = fbdo.to<bool>();
  }

  // Task 2: Pump Control Logic (Manual / Auto / Safety Lock)
  if (isWaterLow) {
    digitalWrite(PUMP_PIN, LOW);
    isPumpIntervalWaiting = false;
  } 
  else if (pumpManual) {
    digitalWrite(PUMP_PIN, HIGH);
    isPumpIntervalWaiting = false;
  } 
  else {
    if (soilRaw >= soilMin && !isPumpIntervalWaiting) {
      digitalWrite(PUMP_PIN, HIGH);
      lastPumpTime = currentMillis;
      isPumpIntervalWaiting = true; 
    }

    if (isPumpIntervalWaiting) {
      if (digitalWrite(PUMP_PIN) == HIGH && (currentMillis - lastPumpTime >= PUMP_RUN_DURATION)) {
        digitalWrite(PUMP_PIN, LOW);
        lastPumpTime = currentMillis; 
      } 
      else if (digitalWrite(PUMP_PIN) == LOW && (currentMillis - lastPumpTime >= PUMP_WAIT_DURATION)) {
        isPumpIntervalWaiting = false;
      }
    }
  }

  // Task 3: Light Control Logic
  if (lightManual) {
    digitalWrite(LIGHT_PIN, HIGH);
  } else {
    if (lux < luxMin) {
      digitalWrite(LIGHT_PIN, HIGH);
    } else {
      digitalWrite(LIGHT_PIN, LOW);
    }
  }
}
